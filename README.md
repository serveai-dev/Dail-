# BP Learning redesign (Eagle Day, track A3)

A redesigned learner path for a pharmacy communication training in Casablanca: French and Arabic, voice, docked feedback, printable attestation. Runs fully in the browser.

- Start here: [bp-learning-morocco-frontend-candidate/README.md](bp-learning-morocco-frontend-candidate/README.md)
- Evidence: [docs/evidence/](docs/evidence/) (before, after, keyboard run, user test)
- Design and plan: [docs/superpowers/](docs/superpowers/)

Run: `cd bp-learning-morocco-frontend-candidate && python -m http.server 8089`, then open http://127.0.0.1:8089/
